## Thursday or Friday — one command (found 2026-09-17 morning; do this before Saturday)

The simulator's default marginals come from the TabPFN projection cache, which is regenerated by a GPU job that has no
scheduler: it must be run by hand each week. It has not run for Week 2 (the cache holds Week 1 only), so every Week-2
build so far fell back to the empirical marginals with a logged warning. Run once (≈ 2 minutes, ≈ $0.05):
```
gcloud run jobs execute tabpfn-gen --project nfl-predictions-503414 --region us-central1 --update-env-vars TABPFN_UPCOMING=2026:2 --wait
```
Check: `bq query --use_legacy_sql=false 'SELECT week, COUNT(*) FROM nfl_features.tabpfn_projections WHERE season=2026 GROUP BY 1'`
must now show a week-2 row (≈ 900 players). The same command is repeated inside the Saturday refresh (step 2 below).
